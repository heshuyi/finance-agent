## 背景

用户通过 Web 页面与 FinTeam Agent 对话，并实时查看任务进度与子 Agent 状态。M0 通过 AG-UI 协议连接 MainAgent，展示流式对话与 State 同步面板。

## 需求范围

### 必须交付

1. **Next.js 应用** `frontend/`
   - App Router + TypeScript + Tailwind

2. **AG-UI 集成**
   - `src/app/api/copilotkit/route.ts` — HttpAgent 代理至 `http://127.0.0.1:8000/agent`
   - `src/app/providers.tsx` — CopilotKit Provider，`agent=finteam_main`

3. **页面组件**
   - `FinTeamChat` — 对话区（CopilotChat）
   - `AgentStatusPanel` — 展示 phase、progress、sub_agent_status

4. **配置**
   - `frontend/.env.local.example` — `AGENT_URL`
   - `scripts/dev-frontend.sh`

### 非目标（M0 不做）

- 多空辩论四栏完整 UI（M1+）
- 终裁报告独立页（M2）
- 历史记录（M3）

## 验收标准

- [ ] `npm run dev` 后访问 http://localhost:3000 显示 FinTeam 对话页
- [ ] 后端运行时，发送消息可流式收到回复
- [ ] 状态面板显示 phase、进度条、8 个子 Agent 状态行
- [ ] `npm run build` 通过（@ag-ui/client 版本与 CopilotKit 兼容）
