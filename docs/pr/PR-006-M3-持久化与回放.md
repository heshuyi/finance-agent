## 背景

个人投研需要复盘历史研判。M3 将 Task 日志、Artifact 链与 LangGraph Checkpoint 持久化到 SQLite，前端提供历史列表与回放。

## 需求范围

### 必须交付

1. **存储** `storage/` — SQLite schema、Task / Artifact 读写
2. **MainAgent** — `persist_task` 节点写入 DB
3. **API** — `GET /tasks`、`GET /tasks/{id}` 查询历史
4. **前端** — 历史侧栏、研判详情回放页

## 验收标准

- [ ] 完整研判结束后可在历史页打开，报告与 Artifact 与当时一致
- [ ] 全链路 `task_id` 可追踪 AG-UI → A2A → DB

## 非目标

- 多用户 / 云端部署
