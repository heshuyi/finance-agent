## 背景

FinTeam Agent 是面向个人自用的金融投研多 Agent 系统。在编写代码前，需先明确产品目标、Agent 分工、协议选型与验收标准。

## 需求范围

### 必须交付

1. **主 PRD 文档** `docs/prd/financial-team-agent-prd.md`
   - 背景、目标、非目标
   - 8 个子 Agent 能力规格
   - LangGraph + A2A + AG-UI 架构
   - 里程碑 M0–M3
   - 验收标准与非功能需求

2. **附录**
   - `references/schemas.md` — Artifact / State Schema
   - `references/agent-cards.md` — A2A Agent Card 样例

3. **PRD 空白模板** `.cursor/skills/finance-agent-pm/references/prd-template.md`

- 不绑定第三方 Agent 平台（万得 Alice 等）
