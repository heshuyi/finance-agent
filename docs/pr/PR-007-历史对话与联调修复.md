# PR-007：历史对话、CopilotKit Threads 与侧栏刷新

| 字段 | 内容 |
|------|------|
| 对应分支 | `feat/pr007-history-chat` |
| 类型 | 修复 / 体验 |
| 里程碑 | M3+ |
| 依赖 | PR-006 |

## 背景

M3 联调发现：

1. `GET /api/copilotkit/threads` 返回 **404** — 当前 Next.js 路由仅导出 `POST`，且使用 single-route 模式，无法响应 CopilotKit 多路由 Threads API
2. **历史研判**侧栏仅在页面加载时拉取一次，新研判完成后需手动刷新
3. 用户需要 **历史对话**（CopilotKit 会话线程）与 **历史研判**（SQLite Task）并列可用

## 需求范围

### 必须交付

1. **CopilotKit Runtime**
   - 改为 multi-route `createCopilotRuntimeHandler` + `[[...slug]]` catch-all
   - 导出 `GET` / `POST` / `OPTIONS`
   - 使用 `InMemoryAgentRunner` 支持本地 Threads 列表

2. **历史对话侧栏**
   - 调用 `GET /api/copilotkit/threads?agentId=finteam_main`
   - 点击切换 `threadId`，支持「新对话」

3. **历史研判侧栏**
   - 研判完成（`phase=done`）后自动刷新
   - 窗口重新聚焦时刷新

4. **布局**
   - 左侧双 Tab：历史对话 | 历史研判

## 验收标准

- [x] 浏览器 Network 中 `GET /api/copilotkit/threads` 返回 200（非 404）
- [x] 完成一次对话后，历史对话列表出现该线程（InMemoryAgentRunner 本地内存）
- [x] 新研判完成后，历史研判列表自动更新（`phase=done` 触发刷新）
- [x] 点击历史对话可切换会话上下文（`threadId` + `CopilotChat key`）

## 非目标

- 对话消息持久化到 SQLite（CopilotKit Intelligence 云同步）
- 多用户 / 登录
