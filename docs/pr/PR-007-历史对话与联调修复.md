## 背景

M3 联调与后续投研能力建设发现：

1. `GET /api/copilotkit/threads` 返回 **404** — Next.js 路由仅 `POST` + single-route，无法响应 CopilotKit Threads API
2. **历史研判**侧栏仅在页面加载时拉取，研判完成后需手动刷新
3. 用户需要 **历史对话**（CopilotKit 线程）与 **历史研判**（SQLite Task）并列可用
4. 行情/资讯/公告需通过 Tool 层拉取并整理为 **ai_context** 供 LLM 分析，而非向用户 dump 原始 JSON
5. 数据获取需满足个人投研场景的**合法合规**要求（授权 API 优先、披露接口独立、第三方资讯默认关闭）

## 需求范围

### 必须交付

#### 1. CopilotKit Runtime（PR-007 核心）

- multi-route `createCopilotRuntimeHandler` + `[[...slug]]` catch-all
- 导出 `GET` / `POST` / `OPTIONS`
- `InMemoryAgentRunner` 支持本地 Threads 列表
- `useSingleEndpoint={false}` + `threadId` 会话切换

#### 2. 历史侧栏

- 双 Tab：**历史对话** | **历史研判**
- 对话：`GET /api/copilotkit/threads?agentId=finteam_main`
- 研判：`phase=done` 与窗口聚焦时自动刷新
- 支持「新对话」与线程切换（`CopilotChat key={threadId}`）

#### 3. 投研 Tools 层

- `tools/` — 行情（AKShare）、资讯（Finnhub + 可选公开列表）、公告（巨潮法定披露）
- `LocalCache` — SQLite `content_cache`，90 天 TTL，本地优先
- `ai_context` — 多源合并为 LLM 可读上下文
- `GET /tools/*` — 供 CopilotKit Frontend Tools 调用
- `data_collector` 接入真实 Tool，写入 `metadata.ai_context`

#### 4. 快问快答与路由

- `data_query` / `general`（含标的）→ `chat_response` + 自动注入 `ai_context`
- 买入/卖出/验真仍走完整 pipeline
- `chat_response` 完成后 `persist_task` 入库

#### 5. 合规（fix/compliance）

- `FILINGS_FETCH_ENABLED` 与 `NEWS_FETCH_ENABLED` 独立开关
- 资讯默认关闭，Finnhub 授权 API 优先
- `auto` 行情链移除 Ashare 网页抓取默认回退
- `tools/compliance.py` 数据使用说明与资讯 URL 白名单

#### 6. 工程

- `.cursor/skills/code-review/` — 提交前 Code Review 流程
