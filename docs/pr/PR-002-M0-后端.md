## 背景

用户通过 AG-UI 与**主 Agent**对话。M0 阶段主 Agent 需完成意图解析、任务状态初始化，并通过 FastAPI 暴露 AG-UI 流式端点。子 Agent 尚未接入 A2A，但 State 字段需预留。

## 需求范围

### 必须交付

1. **项目结构**
   - `pyproject.toml` — Python 依赖（langgraph、ag-ui-langgraph、fastapi）
   - `.env.example` — LLM / API 配置模板
   - `agents/shared/state.py` — MainAgentState（含 phase、progress、sub_agent_status）
   - `agents/shared/intent.py` — 意图与标的解析（规则版）

2. **MainAgent LangGraph**
   - 节点：`prepare_task` → `chat_response`
   - Checkpointer：`MemorySaver`
   - 输出更新 AG-UI 同步字段（phase、progress、planned_agents）

3. **FastAPI 服务**
   - `api/main.py` — AG-UI endpoint `/agent`
   - `/health` 健康检查
   - CORS 允许 `localhost:3000`

4. **开发脚本**
   - `scripts/dev-api.sh`

### 非目标（M0 不做）

- A2A 子 Agent 真实调度
- 数据连接器真实取数
- SQLite 持久化

## 验收标准

- [ ] `curl http://127.0.0.1:8000/health` 返回 `{"status":"ok"}`
- [ ] 配置 `OPENAI_API_KEY` 后，POST `/agent` 可流式返回
- [ ] 用户输入「分析茅台是否值得买入」，State 中 `intent=buy_analysis`，`planned_agents` 含 data_collector 等
- [ ] 未配置 API Key 时返回占位回复，不崩溃

## 技术约束

- Python 3.12+，LangGraph 1.x
- 全自研，不依赖商业 Agent SDK
